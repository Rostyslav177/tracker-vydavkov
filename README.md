# Tracker výdavkov

Jednoduchá desktopová aplikácia na evidenciu výdavkov, vytvorená v Pythone s grafickým rozhraním (Tkinter).

## Funkcie
- pridávanie výdavkov (popis, suma, kategória, dátum sa nastaví automaticky)
- zobrazenie v tabuľke a filtrovanie podľa kategórie
- mazanie vybraných záznamov
- automatický súčet výdavkov
- ukladanie údajov do súboru CSV

## Použité technológie
- Python 3
- Tkinter (GUI)

## Použitý AI tool
- Claude (Anthropic) – pomoc s návrhom a písaním kódu
